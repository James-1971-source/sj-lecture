## 1. 여는 방법

### 가장 간단한 방법
`index.html` 파일을 더블클릭하면 기본 브라우저에서 바로 열립니다.
인터넷 연결 없이도 동작합니다. (글꼴만 온라인에서 받아오므로, 오프라인에서는 기본 글꼴로 표시됩니다)

### 강의장에서 권장하는 방법
1. 폴더 전체를 USB에 담아 갑니다.
2. 강의장 PC에서 `index.html`을 엽니다.
3. 회차 카드를 눌러 해당 슬라이드로 들어갑니다.
4. **F 키**를 눌러 전체화면으로 전환합니다.

### 로컬 서버로 여는 방법 (선택)
```bash
python -m http.server 5180
```
브라우저에서 `http://localhost:5180` 접속.

## 2. 강의 중 조작법

| 키 | 기능 |
|---|---|
| `→` `Space` `Enter` `↓` `PageDown` | 다음 슬라이드 |
| `←` `↑` `PageUp` | 이전 슬라이드 |
| `Home` / `End` | 첫 장 / 마지막 장 |

| `F` | 전체화면 |

## 3. 슬라이드 안의 인터랙션 — **모두 강사가 조작합니다**

> **운영 원칙**
> 참여 청년들은 개인 PC가 없습니다. 따라서 **교육생이 기기를 다루는 순서는 전 회차에 하나도 없습니다.**

> 교육생은 보고 듣고, 말로만 참여합니다.

## 6. 파일 구성

```
index.html        허브 — 과정 개요, 회차 카드, 강사 소개, 사용법
session1.html     1회차 슬라이드 (30장)
session2.html     2회차 슬라이드 (25장)
session3.html     3회차 슬라이드 (26장)
assets/
  style.css       디자인 시스템 전체 (색·타이포·컴포넌트·인쇄 스타일)
  deck.js         슬라이드 엔진 + 인터랙션 + 배경 애니메이션
.claude/
  launch.json     로컬 미리보기 서버 설정
```

### 내용을 고치고 싶을 때
- 슬라이드 하나 = `<section class="slide" data-title="목차에 뜰 제목" data-part="상단 파트명">` 한 덩어리입니다.
- 순서를 바꾸려면 `<section>` 블록 통째로 위치를 옮기면 됩니다. 번호·목차·진행바는 자동으로 다시 계산됩니다.
- 새 슬라이드를 넣을 때는 기존 블록을 복사해 내용만 바꾸는 것이 가장 안전합니다.
- 내부 요소에 `class="reveal"`을 붙이면 등장 애니메이션이 순서대로 적용됩니다.
